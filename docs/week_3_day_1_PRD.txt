PRD: Task — Golden Tests (Correctness Lock)
1. Context & Goal
Objective: Implement a "Correctness Lock" mechanism to prevent mathematical regressions. We need to run the core calculation engine against a set of "Golden Recipes" (verified Ground Truth data from Excel) and ensure the output matches exactly within a tight tolerance. Approach: Create a dedicated CLI script (npm run test:golden) that acts as a standalone test runner. Priority: High (Must be completed before further refactoring).

2. Technical Specifications
A. The Data Source: src/tests/golden-data.ts
We need a typed data file containing the test cases.

Interface: GoldenTestCase (Input ingredients vs. Expected output metrics).

Data Content: Must include the "Excel Validation Master" and "Butter Consistency Check" cases provided in the data block below.

B. The Test Runner: src/scripts/run-golden.ts
A TypeScript script that executes the tests.

Dependencies: Uses ts-node (or tsx) to run directly from the terminal.

Logic:

Import calculateRecipe (or equivalent main function) from src/lib/calc.v2.ts.

Iterate through GOLDEN_TEST_CASES.

Feed inputs into the engine.

Compare actual results vs. expected values.

Tolerance: Allow a delta of ±0.05 for percentages and ±1.0g for weights.

Output: Print a summary table. Use standard console colors (Green for PASS, Red for FAIL).

Exit Code: Exit with 1 if any test fails (for future CI/CD compatibility).

C. Execution
Add a script to package.json: "test:golden": "ts-node src/scripts/run-golden.ts"
